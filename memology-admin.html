🔐 Вход для админа

Менять мемы, ситуации и смотреть предложения может только админ.

🛡️ Последний шаг

Ты вошёл как , но база ещё не знает, что ты админ.

1. Нажми «Скопировать SQL»
2. Supabase → SQL Editor → New query → вставь → Run
3. Вернись сюда и нажми «Проверить снова»
После этого всё, кроме чтения мемов и ситуаций и отправки предложений, будет доступно только тебе.
